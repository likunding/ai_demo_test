核心工具代码说明：

1. CSV读取工具类：
   - 负责读取CSV文件到内存
   - 使用Apache Commons CSV库
   - 支持指定分隔符、编码格式
   - 自动识别表头
   - 支持分页读取大文件

2. 数据库连接池工具：
   - 基于HikariCP实现
   - 配置项包含：maximumPoolSize=20, connectionTimeout=30000
   - 支持多数据源切换
   - 自带连接健康检查
   - 自动打印慢SQL日志

3. Redis分布式锁工具：
   - 使用SETNX + EX原子指令实现
   - 支持自动续期（watch dog机制）
   - 支持可重入
   - 防死锁：业务异常自动释放
   - 最大持有时间默认30秒

4. JWT鉴权工具类：
   - 生成access_token（有效期2小时）
   - 生成refresh_token（有效期7天）
   - 支持自定义claims载荷
   - RSA256非对称签名
   - token黑名单机制

5. FastAPI分页接口规范：
   - 统一请求参数：page（默认1）、page_size（默认20，最大100）
   - 统一响应格式：{code, data:{list, total, page, page_size}, message}
   - 参数校验使用Pydantic模型
   - 数据库层使用limit/offset分页，大表建议使用游标分页
